# Go ジェネリクス — 実務寄りの例

Go 1.18 以降のジェネリクスを、小さなプログラムで学ぶためのリポジトリです。  
`main.go` にコメント付きの例がまとまっています。

## 実行

```bash
go run .
```

Go 1.22 以上を想定しています。

## 含まれる例

| # | 内容 | 制約 |
|---|------|------|
| 1 | `Filter` / `Map` — スライスの絞り込み・変換 | `any` |
| 2 | `DecodeJSON` — JSON を型指定でデコード | `any` |
| 3 | `Result` — 成功/失敗を1つの値にまとめる | `any` |
| 4 | `Set` — 重複のない集合 | `comparable` |
| 5 | `Cache` — キー・値型付きのインメモリキャッシュ | キー `comparable` / 値 `any` |

## 読む順番

1. 例 1〜3 … 制約は `any`（どんな型でも OK）だけ  
2. 例 4〜5 … `comparable`（`==` で比べられる型。map のキーに使うときに必要）

## 制約のざっくりメモ

- **`any`** — 制約なし。まずはこれで十分なことが多い  
- **`comparable`** — `int` / `string` など `==` できる型。スライスや map は NG
